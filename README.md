# GymGramps

Aplicativo web para acompanhar rotina de treino e alimentação, com foco em praticidade e em uma interface brutalista (alto contraste, fontes grandes, navegação direta).

Projeto da disciplina **Projeto Integrador 2** — Bacharelado em Sistemas de Informação, UNIRIO.

## Integrantes

- Daniel Almeida Zuvanov
- Willyam Eduardo de Souza Filho

## Funcionalidades previstas

- Cadastro, login e perfil do usuário
- Painel de rotina em formato de fita de 24 horas
- Plano alimentar com refeições e macronutrientes
- Chat entre usuários

## Tecnologias

- Front-end: React + Vite
- Infraestrutura: Supabase (autenticação e PostgreSQL)
- Banco relacional: PostgreSQL 16
- Banco não relacional: MongoDB
